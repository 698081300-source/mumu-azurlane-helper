  1. 解压到任意文件夹（不要放在 C 盘系统目录），双击 MuMu碧蓝助手.exe
  2. 在 MuMu 里打开《碧蓝航线》，回到小窗填关卡（如 12-4），点「一键三星」
  3. 以后不用再下载 —— 工具会自己更新；有新版会在日志第一行提示
需要自己装 Alas 吗？

需要。这个壳只是把 Alas 用起来，不包含也不修改 Alas。请先按 Alas 官方教程装好，壳会自动找到它。

打不开 / 被杀毒软件拦？

新版 Windows 可能会提示"未知发布者"，点「更多信息 → 仍要运行」即可。如果实在进不去，把 %APPDATA%\MuMu碧蓝助手 下最新的 crash-*.log 发给我。

支持哪些玩法？

只做三件事：一键三星过图、刷光石油、清日常（收获 / 委托 / 科研 / 后宅 / 白嫖奖励）。别的设置请直接开 Alas。
