MuMu 碧蓝助手 · 使用说明（测试版）
=================================

一、先装好三样东西（缺一样都跑不起来）
------------------------------------
1. MuMu 模拟器（12 或 15 都可以）
2. 把《碧蓝航线》装进模拟器里，并登录到主界面
3. Alas（本工具**不包含** Alas，需要你自己下载安装）
   下载页：https://alas.azurlane.cloud/
   下带 fullcn 的整合包（AlasApp_x.x.x_fullcn.7z），解压就能用，别下 Source code
   解压到**全英文路径**（例如 D:\Alas），中文路径容易报错
   注意：选文件夹时要选到 AzurLaneAutoScript 这一层
   —— 里面有 alas.py、config、toolkit 的那一层


二、第一次打开
--------------
1. 把压缩包**解压**到任意文件夹（不要在压缩包里直接双击运行）
2. 双击 MuMu碧蓝助手.exe
   · 如果提示"Windows 已保护你的电脑" → 点「更多信息」→「仍要运行」
3. 第一次会问 Alas 装在哪 → 选到 AzurLaneAutoScript 那一层
   记住之后就不再问了；以后 Alas 挪了位置，点「选 Alas 文件夹」可以重选


三、怎么用
----------
· 主线图：关卡填 12-4（打完自动下一关）；要打困难图，把「打困难图」打开
· 活动图：关卡填 C2 / D3 这种代号
· 刷光石油：只刷填好的这一关，石油不足 500 会自动停
· 清日常：收获 / 委托 / 科研 / 后宅 / 白嫖奖励（点一次全干完）
· 活动每日：当前活动的 A / B / C / D / SP 各打一次
  活动期间每天点一次就行，漏一天就少一次三倍奖励

· 想停 → 「停止」
· 想自己改 Alas 的设置 → 「打开 Alas 设置」
  注意：别在 Alas 界面里点「启动」，会和这个助手抢同一个模拟器
· 「还原 Alas 初始配置」= 把 Alas 设置放回助手改动之前的样子（不是清空助手自己的设置）


四、出问题怎么办
----------------
日志区最后几行就是原因；随时可以点「停止」刹车。

失败了请把这两样发给我：
1. 小窗截图（日志区那几行文字）
2. 这个文件夹里最新的 onetap_*.log
   %APPDATA%\MuMu碧蓝助手\logs\

（在资源管理器地址栏粘 %APPDATA%\MuMu碧蓝助手 就能打开）
